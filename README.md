# 小岛奇遇 · Unity 2D

Unity 2022.3.34f1c1。原 VR 模板已替换为原生 Unity/C# 版本，不依赖浏览器或 Meta XR。

在 Unity Hub 中添加此目录，使用匹配版本打开。打开 `Assets/Scenes/Island.unity`，点击 Play。场景已加入 Build Settings；编辑器菜单 `Island/生成并打开游戏场景` 可在场景被删除时重新生成。

WASD / 方向键移动；按住鼠标指向任意方向移动；靠近果蔬按 E 逐个采集；靠近白猫按 E 对话；左侧按钮展开背包。

已迁移：开始页、岛屿放大/闪白转场、3倍跟随镜头、小狗透明抠图与待机、白猫NPC、果蔬采集/飞入背包/两次跳跃、像素地图与鸟、地图通行遮罩及桥面规则。

实现说明：地图为整张背景图，碰撞采用与网页一致的颜色遮罩加显式禁行区域，并非逐块 Tilemap。界面目前使用原生 IMGUI，后续可替换为 Canvas Prefab。

已补齐水面/瀑布动态、四腿独立摆动、狗爪图标和气泡尾巴。待 Unity 编辑器验收：本次制作环境没有 Unity，未执行编译或 Play Mode，不能将静态检查当作最终运行验收。
